# Personal Digital Marketing Portfolio — Harsh Anand

## Included
- `index.html` — content and semantic page structure.
- `css/style.css` — all visual styling, layout, responsive breakpoints, and reduced-motion rules.
- `js/script.js` — mobile navigation, footer year, scroll reveal, and contact form behavior.
- `assets/IMAGE_REFERENCE_GUIDE.md` — image slots, recommended file names, and image guidance.
- `assets/portrait-reference.svg` — an illustrative placeholder, not a real portrait.
- `CODE_MAP.md` — explains which part of each code file controls which website section.
- `portfolio_content_blueprint.md` — section-by-section content and launch checklist.

## Preview locally
1. Extract the ZIP.
2. Keep all files/folders together.
3. Open `index.html` in a modern browser.

## Before publishing
- Replace the portrait placeholder with your own professional photo.
- Replace all sample case study content with real work and verified outcomes.
- Label concept projects clearly and get permission before showing client names/logos/screenshots.
- Update your real email, LinkedIn, and Instagram links.
- In `js/script.js`, replace `YOUR_EMAIL@example.com` with your real email address.
- Test the form, links, mobile menu, spelling, and responsive layout.

## Contact form limitation
The form prepares an email in the visitor's default email app. It does not store submissions or send them directly from the website. For a production form, connect a trusted form service or backend.

## Publishing
You can host the project folder on GitHub Pages, Netlify, Vercel, or your current web host.
